## Problem Statement

Evaluate the performance of Binary Search in concurrent environments with multiple simultaneous search queries. Measure execution time under load and analyze the scalability and efficiency of Binary Search.

## Algorithm Used

* Binary Search
* POSIX Threads (Multithreading)

## Features

* Performs Binary Search on a sorted array.
* Executes multiple search queries concurrently.
* Measures execution time.
* Demonstrates Binary Search scalability.

## Learning Outcomes

* Understand Binary Search.

* Evaluate algorithm scalability.
