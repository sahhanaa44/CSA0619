## Problem Statement

A medical imaging system sorts patient scan records based on scan time and priority using the Merge Sort algorithm. The program demonstrates stable sorting while maintaining the relative order of records having the same priority.

## Algorithm Used

* Merge Sort
* Divide and Conquer Technique

## Features

* Stable Sorting
* Efficient for large datasets
* Time Complexity: O(n log n)
* Suitable for medical imaging systems where accuracy is important.

## Output

The program displays:

* Original Patient Scan Records
* Sorted Patient Scan Records (Highest Priority First)

## Learning Outcomes

* Understand Merge Sort.
* Apply Divide and Conquer.
* Analyze Time Complexity.
* Study stability in sorting algorithms.
