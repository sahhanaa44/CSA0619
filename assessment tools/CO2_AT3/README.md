# Question 36 – Debugging Convex Hull Logic

## Aim
Debug and improve the brute force Convex Hull algorithm to correctly handle collinear points and validate hull edges.

## Files Included
- `Source_Code/convex_hull.py`
- `Report/Question_36_Report.docx`

This program analyzes the flaw in the given Convex Hull edge validation logic, implements the corrected solution, optimizes orientation checks, and analyzes the time complexity.

## Software Used

- Visual Studio Code

## How to Run

python convex_hull.py
