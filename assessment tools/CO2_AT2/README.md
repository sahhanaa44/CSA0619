# Question 36 – Linear Search

## Aim
Implement the Linear Search algorithm in C to search for a product in an unsorted retail product list.

## Files Included
- `Source_Code/linear_search.c`
- `Report/Question_36_Report.docx`

## Description
This program demonstrates the Linear Search algorithm and includes an analysis of its performance, along with a comparison with Binary Search for an unsorted dataset.

## Software Used
- GCC Compiler
- Visual Studio Code

## How to Run

Compile:
```bash
gcc linear_search.c -o linear_search
```

Run:
```bash
./linear_search
```
